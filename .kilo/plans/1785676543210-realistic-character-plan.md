# План: Замена персонажа на реалистичного

## Цель
Заменить текущий SVG-человечка (stick-figure) на более реалистичного персонажа, который реагирует на погодные условия.

## Ограничения
- vanilla JS, без сборщиков
- офлайн-режим (PWA)
- персонаж должен меняться в зависимости от температуры/погоды
- без внешних зависимостей

## Исследовано
1. **DiceBear** — популярная библиотека аватаров (50+ стилей), ESM-only в v10, требует npm/build tools для JS-библиотеки. HTTP API (`api.dicebear.com`) работает без сборки, но требует сети.
2. **Multiavatar** — 12 млрд уникальных аватаров, vanilla JS, но cartoon-style.
3. **AvataaarsJs** — стиль Avataaars от Pablo Stanley, требует сборки.
4. **Самописный SVG** — полный контроль, офлайн-работа, но больше работы.

## Рекомендация
Для этого проекта (PWA, offline-first, vanilla JS) оптимально **улучшить существующий самописный SVG-персонаж**, сделав его более детализированным и реалистичным, без внешних зависимостей.

### Почему не библиотека:
- DiceBear требует сети для HTTP API или сборки для JS-версии
- Любая внешняя зависимость нарушает offline-first
- Самописный SVG даёт полный контроль над реакцией на погоду

## План реализации

### Шаг 1. Улучшить `updatePerson()` в `script.js`
- **Голова**: эллипс с зачёсыванием волос, глаза с зрачками и бликами, брови, нос, рот
- **Тело**: более реалистичные пропорции, шея, торс
- **Одежда**: varies by temperature
  - < 0°C: зимняя куртка, шапка, шарф, перчатки
  - 0-10°C: куртка, шапка
  - 10-20°C: свитер/кофта
  - 20-28°C: футболка/рубашка
  - > 28°C: лёгкая одежда
- **Ноги**: брюки/шорты в зависимости от температуры
- **Обувь**: ботинки/кроссовки/сандалии
- **Аксессуары**:
  - Дождь: зонт + капюшон
  - Жара: солнцезащитные очки
  - Холод: шапка + шарф
