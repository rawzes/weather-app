# Weather Companion

Погодное PWA-приложение, которое показывает текущую погоду, почасовой и недельный прогноз, рекомендации по одежде и позволяет управлять избранными городами — всё прямо в браузере.

![Погодное приложение](icon.svg)

## Возможности

- **Текущая погода** — температура, ощущаемая температура, влажность, давление, ветер и порывы.
- **Почасовой прогноз** — до 12 часов вперёд.
- **Недельный прогноз** — мин/макс температура на 7 дней с визуальной полосой.
- **Рекомендации по одежде** — автоматический совет на основе температуры, осадков и ветра.
- **Иллюстрация одежды** — SVG-фигура человека, которая меняется в зависимости от погоды и температуры.
- **Поиск городов** — через OpenStreetMap Nominatim.
- **Геолокация** — определение местоположения по GPS устройства или по IP (резерв).
- **Избранное и история** — до 8 городов в каждом списке.
- **Темы оформления** — светлая, тёмная и автоматическая (по времени суток).
- **Переключение единиц** — °C / °F.
- **Offline-режим** — Service Worker кэширует оболочку приложения; последний успешный прогноз показывается без сети.
- **PWA** — манифест, service worker, установка на домашний экран.

## Технологии

| Технология | Назначение |
|---|---|
| HTML5 | Семантическая структура |
| CSS3 (переменные, Grid, Flexbox) | Адаптивная вёрстка, темы, анимации |
| Vanilla JavaScript | Вся прикладная логика без сборщиков и зависимостей |
| Service Worker | Кэширование оболочки приложения, offline-режим |
| Web App Manifest | PWA-метаданные для установки |

## Интеграции

- **Open-Meteo** — бесплатный API погоды (текущая погода, почасовой и недельный прогноз). Не требует API-ключа.
- **OpenStreetMap Nominatim** — геокодирование и обратное геокодирование.
- **ipapi.co** — определение местоположения по IP (резервный способ).

## Запуск

Проект не требует сборки, зависимостей или серверной части. Достаточно статического HTTP-сервера.

```bash
# Python 3
python3 -m http.server 8000

# Node.js (npx)
npx serve .
```

Откройте `http://localhost:8000` в браузере.

> **Примечание:** для работы геолокации и Service Worker необходим HTTPS (или `localhost`).

## Развёртывание

Проект готов к публикации на **GitHub Pages**. Он уже развёрнут по адресу: https://rawzes.github.io/weather-app/

При пуше в ветку `main` автоматически запускается workflow из `.github/workflows/deploy-pages.yml`.

Также можно развернуть на любом статическом хостинге (Netlify, Vercel, Surge и т.д.), просто указав корень репозитория как корневую директорию.

## Локальное хранение

Данные сохраняются в `localStorage` под следующими ключами:

| Ключ | Содержимое |
|---|---|
| `weatherApp.unit` | Единицы температуры: `c` или `f` |
| `weatherApp.theme` | Тема: `auto`, `light` или `dark` |
| `weatherApp.lastLocation` | Последняя локация (имя, широта, долгота) |
| `weatherApp.lastSnapshot` | Последний нормализованный прогноз |
| `weatherApp.favorites` | Избранные города (до 8) |
| `weatherApp.history` | История поиска (до 8 уникальных) |
